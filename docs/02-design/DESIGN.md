# 설계

> **수식 · 타입 · 모듈 경계.**

**현재 상태: 미정의.** 계산할 제품이 정의되지 않았습니다. Phase 1 이후에 채웁니다.

## 채울 항목

| 항목      | 답하는 질문                                     |
| --------- | ----------------------------------------------- |
| 모듈 경계 | 어떤 모듈이 어떤 질문에만 답하는가              |
| 의존 방향 | 모듈이 누구를 import하는가 (단방향)             |
| 타입      | 도메인 타입과 스키마의 정본은 어디인가          |
| 수식      | 각 공식의 근거는 어느 원문의 어느 줄인가        |
| 실패 표현 | 알 수 없는 값을 어떻게 표현하는가 (`T \| null`) |

## 미리 정해진 경계 (Phase 0)

| 경로             | 담는 것                               | 의존         |
| ---------------- | ------------------------------------- | ------------ |
| `src/routes/`    | 라우트 선언. TanStack Router          | `router.tsx` |
| `src/router.tsx` | 라우터 생성. `getRouter`를 내보냄     | `routes/`    |
| `src/app/`       | 앱 뼈대. 전역 스타일                  | —            |
| `scripts/`       | CLI 진입점. **호스트 환경 참조 가능** | `src/`       |
| `test/`          | `node --test`. 한 파일 = 한 모듈      | 전부         |

`src/lib/`, `src/data/`, `src/ui/`, `src/pages/`는 **기획이 끝난 뒤** 만듭니다.
Phase 0에서 빈 폴더를 만들지 않습니다.

## CSR 전제가 경계에 미치는 영향

SPA 모드에는 서버가 없습니다. `src/` 코드에 `process`·`os`·`child_process`·`node:`·
`fetch`를 넣지 않습니다. 호스트 환경이 필요한 계산은 `scripts/`로 내립니다. 계산이
서버에서 실행되면 호스트 사양이 결과에 섞입니다.
