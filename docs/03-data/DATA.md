# 데이터

> **데이터가 어디서 왔나 · 신뢰도 · 신선도.**

**현재 상태: 데이터 없음.** 어떤 데이터를 다룰지 Phase 1이 정합니다. 아래는 데이터가
생기기 전에도 성립하는 규칙입니다.

## 규칙

### 손으로 고치지 않습니다

수집으로 만들어지는 파일은 사람이 고치지 않습니다. 다음 실행에 지워집니다. 손으로
고칠 값이 필요하면 시드에 넣고 파생에서 제외합니다.

### 출처가 모순되면 자동 반영하지 않습니다

출처가 서로 다르면 **보고만 하고, 사람이 고릅니다.** 자동 덮어쓰기를 하면 이미 맞다고
확인한 값이 출처의 오류에 밀려 사라지고, **틀렸다는 단서까지 없어집니다.**

### 원재료를 저장합니다

결과 값 하나만 저장하면 **틀렸는지 확인할 방법이 없습니다.** 검산 가능한 형태를
남깁니다.

```text
✗ total: 100
✓ partA: 20, partB: 80  →  20 + 80 = 100  (검산 가능)
```

### 출처를 적습니다

데이터마다 출처와 확인일을 함께 기록합니다. **어느 원문의 어느 줄**인지 적어야 다음
사람이 같은 확인을 반복할 수 있습니다.

### 신선도를 노출합니다

`collectedAt` · `specConfidence` · `unresolvedFields` — 사용자가 데이터의 나이를 알 수
있어야 합니다. 신뢰도를 숨기지 않습니다. 추정인 항목은 **"추정 (관측 0건)"**으로
명시합니다. 조용히 숫자만 두지 않습니다.
