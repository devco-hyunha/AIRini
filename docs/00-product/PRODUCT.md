# 제품

> **왜 · 무엇을 · 무엇을 안 하는가.**
>
> **현재 상태: 미정의.** Phase 1에서 사용자와 함께 정의합니다. 추측으로 채우지
> 않습니다. 검증하지 않은 가정을 적으면 그다음 작업이 틀린 전제 위에서 이어집니다.

## 채울 항목

| 항목        | 답하는 질문                          | 상태   |
| ----------- | ------------------------------------ | ------ |
| 한 줄 정의  | 이 제품은 사용자에게 무엇을 해주는가 | 미정의 |
| 대상 사용자 | 누가, 어떤 장면을 위해 쓰는가        | 미정의 |
| 입력        | 사용자가 무엇을 넣는가               | 미정의 |
| 출력        | 사용자가 무엇을 보는가               | 미정의 |
| 안 하는 것  | 의도적으로 제외하는 것과 그 이유     | 미정의 |
| 신뢰도 원칙 | 계산값의 근거를 어떻게 노출하는가    | 미정의 |

## 왜 "미정의"를 남기는가

기획이 정의되지 않은 상태에서 파일을 만들면, 같은 개념이 여러 파일에 생겨
생성/수정/삭제가 반복됩니다. 그래서 이 표가 채워지기 전에는 제품 파일을 만들지
않습니다.

## 안 하는 것 (Phase 0에서 정해진 것만)

- **서버가 없습니다.** CSR/SPA 모드입니다. 서버 함수를 쓰지 않습니다
- **인증이 없습니다**
- **LLM이 계산하지 않습니다.** 물리와 데이터로 계산합니다 (Phase 1에서 재확인)
